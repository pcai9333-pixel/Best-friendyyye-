# College Payment Portal

## Google Apps Script
The site is configured with the supplied Apps Script Web App `/exec` endpoint.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save and open the generated GitHub Pages URL.

## Important
Keep the Google Sheet itself private. The browser must know the Apps Script web-app endpoint to submit the form, so do not treat that endpoint as a secret.
